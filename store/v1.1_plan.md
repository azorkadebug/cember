# Çember v1.1 — "Tüm Branşlara" Sürümü — Plan

Karar tarihi: 2026-07-01. v1.1'in çekirdeği: Çember'i beden eğitimi odağından çıkarıp **tüm öğretmen branşlarına** uygun hale getirmek. Ana mekanizma: öğretmenin kendi tanımladığı **Kontrol/Yoklama Kalemleri**.

## Kararlar (kullanıcı onaylı)
- Kalemler **branş şablonundan** gelir, **sınıf bazında** düzenlenir.
- İki tür: **günlük ✓/✗** (kitap/boya/forma getirdi mi) + **sayaç** (sezon boyu birikir, sarı kart vb.).
- **Hazır branş şablonları** var (Beden/Resim/Türkçe/Müzik/Matematik/Özel).

## Veri modeli
Sınıf dokümanına eklenir:
```
brans: "beden_egitimi" | "resim" | "turkce" | "muzik" | "matematik" | "ozel"
kontrolKalemleri: [
  { id, ad: "Forma", ikon: "shirt", tip: "gunluk", sira: 0 },
  { id, ad: "Sarı Kart", ikon: "card", tip: "sayac", sira: 1 }
]
```
Günlük yoklama — tarihli kayıt (yeni alt-koleksiyon):
```
siniflar/{id}/yoklamalar/{YYYY-MM-DD}:
  tarih
  kayitlar: { ogrenciId: { geldi: bool, kalemler: { kalemId: bool } } }
```
Sayaç kalemleri öğrenci dokümanında:
```
ogrenci.kalemSayaclari: { kalemId: int }
```

## Branş şablonları
| Branş | Varsayılan kalemler |
|------|---------------------|
| Beden Eğitimi | Forma (günlük), Ayakkabı (günlük), Sarı Kart (sayaç) |
| Resim | Boya (günlük), Fırça (günlük), Resim Defteri (günlük) |
| Türkçe | Kitap (günlük), Defter (günlük) |
| Müzik | Enstrüman/Flüt (günlük) |
| Matematik | Defter (günlük), Ödev (günlük) |
| Özel | (boş) |

## Ekranlar
1. Sınıf oluştur/düzenle: branş seçici → kalemler hazır gelir; Kontrol Kalemleri editörü (ekle/sil/adlandır/ikon/tür/sırala).
2. Yoklama ızgarası: tarih + öğrenci × kalem, tek dokunuşla ✓/✗; "Yeni Ders / Tümü Geldi" sıfırlama; sayaç için +/−.
3. Öğrenci geçmişi: tarihli yoklama + günlük kalem geçmişi + sayaç toplamları.

## Konumlandırma
- Yardım/Store/onboarding metinleri branştan bağımsız.
- Takım kurma + skor → opsiyonel "Etkinlik/Oyun" özelliği.
- Onboarding ilk adımı: branş seç.

## Geriye dönük uyumluluk / göç
- Branşı olmayan sınıflar → `beden_egitimi` varsayılır (fromMap'te default).
- Eski sayaçlar (sariKart/kiyafetEksik/ayakkabiEksik) → varsayılan Beden Eğitimi kalem id'lerine eşlenir.
- Yeni alanlar additive; eski iOS/web istemciler bozulmaz.
