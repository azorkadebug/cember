# Diyalog

Onay diyaloğu: köşe 20px, başlıkta ikon karosu (`ana-50`/`ana`; yıkıcı eylemde `yok-zemin`/`yok-metin`) + 20/700 başlık, gövde 15px satır yüksekliği 1,5.

Başlık eylemi söyler ("Etkinliği Bitir", "Yoklama sıfırlansın mı?"), gövde sonucu söyler ("Skorlar sıfırlanacak."). Düğmeler: "İptal" + fiilli onay ("Evet, Bitir"). Skor ekranında zemin `panel-koyu-2`.
