# SureSayaci

Skor ekranının süre sayacı. `panel-koyu-2` kutu, sayı `sayacSkor` (mono 48/900, harf aralığı 4px).

- Durum renkleri: çalışırken beyaz; son 10 saniyede `sure-uyari` ve hafif nabız; bitince kırmızı ve tam ekran alarm (`alarm-1` ↔ `alarm-2`, "SÜRE BİTTİ" 72/900).
- Başlat düğmesi durum renginin %16'sı üstünde: BAŞLAT (yeşil), DURDUR (turuncu), SÜRE BİTTİ (kırmızı).
- Hazır süreler 52×44 haplar; seçili beyaz %92.
