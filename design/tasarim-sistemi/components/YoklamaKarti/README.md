# YoklamaKarti

Yoklama ekranındaki öğrenci kartı. Sol 4px şerit durumu verir (`geldi-serit` / `yok-serit`), sağdaki düğme hem durumu söyler hem değiştirir.

- "Geldi": `geldi-zemin`, `geldi-cizgi`, metin `basari`. "Yok": `yok-zemin`, `yok-cizgi`, metin `yok-metin`. Renk + ikon + sözcük birlikte.
- Eksik kalem varsa adın yanında `cm-hap--eksik`.
- Karta dokununca kalem çipleri açılır (aynı yeşil/kırmızı haplar, 12/600).

Kullanan sağlar: ad, durum, eksik sayısı. Elle aktarıldı: `yoklama_ekrani.dart:415`.
