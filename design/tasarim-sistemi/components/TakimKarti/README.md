# TakimKarti

Takım Kur sonrası "Takım Dağılımı" sayfasındaki tek takım. Üst bant takım rengi gradyanı (metin `ustMetin`), "Mavi • 3 kişi • (42 puan)"; gövde rengin %3'ü.

- Oyuncu: 22px cinsiyet karosu (açık mavi/pembe), ad 12/500. Kaptan `uyari` 800 + yıldız; eşliler link ikonu.
- 2-3 sütunlu ızgara, 10px aralık; altta "Oyunu Başlat".
