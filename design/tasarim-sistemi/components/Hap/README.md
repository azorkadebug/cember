# Hap

Küçük durum etiketleri. Renk tek başına anlam taşımaz: her hap bir sözcük de içerir.

- `cm-hap--eksik`: `tehlike` üzerinde `tehlike-zemin`, "N eksik" (yoklama kartı).
- `cm-hap--yok`: 9px "Yok", gelmeyen öğrencinin adının yanında.
- `cm-hap--rozet`: `uyari-zemin` rozet çipleri.
- `cm-hap--secili`: `vurgu-zemin` + 2px `vurgu` çerçeve — seçili branş/kart.
- `cm-hap--kalem`: `ana-50` üzerinde kontrol kalemi (simge `ana`, 16px). Kalemin simgesi `KalemSimgeleri`'nden gelir, Material ikonu değil.
