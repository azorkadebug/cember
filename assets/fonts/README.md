# Yazı tipleri

- **Nunito** (gövde) ve **Fredoka** (başlık), SIL Open Font License 1.1 — `OFL-*.txt`.
- Google Fonts deposundaki değişken fontlardan `fonttools varLib.instancer` ile sabit ağırlıklar üretildi (Nunito 400/600/700/800/900, Fredoka 500/600/700).
- **Fredoka değiştirildi (2026-10-04):** orijinalinde ş Ş ğ Ğ İ hazır glif olarak yok; yazı motoru s + çengel diye birleştirince bazı boyutlarda çengel kayıyordu ("Giriş Yap"). Fontun kendi işaretleriyle (uni0327, uni0306, uni0307) bileşik glifler eklendi; konumlar ç/Ç'nin bağlanma kaymasından hesaplandı. Fredoka'nın OFL'unda Reserved Font Name ilan edilmediği için ad korunuyor.
